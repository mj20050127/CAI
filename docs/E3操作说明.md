**E3 操作说明：在 E1 基础增强上加入 MixUp**

截至 2026-11-17，E3 已完成正式 100 轮。最佳验证准确率为 95.62%（第 96 轮），完整验证独立复算一致；第 100 轮为 95.52%。详细对照与 loss 收敛诊断见 [结果分析](../results/E1_vs_E3/analysis.md)。下述步骤保留供理解过程和复现，现有 100 轮训练无需重复；沿用项目现有 .venv，无需安装新依赖。

E1 最佳验证准确率为 95.30%，E2 无增强对照为 89.52%。E3 保留 E1 的随机裁剪和水平翻转，增加 MixUp；主要与 E1 比较，不预设结果一定提高。

**一、这次加入了什么。**

每个训练 batch 完成基础增强、张量转换和归一化后，在 batch 内随机排列出配对图片。本批抽取一个共同的混合系数：

```text
lambda ~ Beta(alpha, alpha)，alpha = 0.2
mixed_x = lambda * x_a + (1 - lambda) * x_b
loss = lambda * CE(logits, y_a) + (1 - lambda) * CE(logits, y_b)
```

图片和标签使用同一个 lambda。两份交叉熵的加权计算与混合 one-hot 软标签交叉熵等价；输入是模型 logits，不额外先做 softmax，也不叠加标签平滑。MixUp 的图片与标签线性混合思想来自 [原论文](https://arxiv.org/abs/1710.09412)，两份标签加权的计算可参阅 [作者发布的 CIFAR-10 实现](https://github.com/facebookresearch/mixup-cifar10/blob/main/train.py)；本项目使用当前环境的 PyTorch 实现并加入配置、日志和续训检查。

本轮应用概率为 1.0，即每个训练 batch 都执行混合。alpha=0.2 控制 Beta 分布，不是固定混入 20%。lambda 可以非常接近 0 或 1；随机排列也可能配到同类或自身，因此并非每张图都会呈现明显的两个不同类别叠加。

训练使用已纳入 checkpoint 的 NumPy 随机状态采样 lambda 和配对排列，不额外消耗基础增强和 Dropout 使用的 Torch 随机流。恢复训练时一并恢复 NumPy、Torch、CUDA 和 DataLoader 随机状态。相同初始模型并不等于不同方法之后的所有随机事件和训练轨迹完全相同。

本次新增日志如下：

| 文件 / 字段 | 含义 |
|---|---|
| history.csv 的 train_objective | 混合标签训练目标，按实际 batch 样本数加权 |

加权训练准确率计算为 lambda×对标签 A 正确数 + (1−lambda)×对标签 B 正确数，再除以样本数。E3 不再把这个量写入普通 train_aug_accuracy 列；旧实验的日志仍兼容。

不要用 E3 的混合训练 loss 或加权训练准确率与 E1 的普通训练指标直接判断优劣。统一比较干净训练监测、完整验证准确率 / loss / Macro-F1；最佳权重仍只按验证准确率、再按验证 loss 选择。监测子集只有固定的 5,000 张训练图片。

正式设置下每轮有 352 个 batch，最后一批为 72 张，所有 batch 均执行 MixUp。完整 100 轮应记录 35,200 条 batch 系数；checkpoint 也保存对应记录，便于中断后恢复 CSV。
