**E6：固定学习率与余弦衰减的对照**

E6 衡量在相同初始学习率和训练预算下，学习率衰减对 CIFAR-10 分类的影响。E1 从 `0.1` 按余弦计划衰减，E6 从第 1 轮到第 100 轮均用 `0.1`。E1 的最佳验证准确率为 95.30%。

| 项目 | E1 | E6 |
|---|---|---|
| 学习率 | 初始 0.1，余弦下限 0.00001 | 固定 0.1 |
| 模型与初始状态 | CIFAR ResNet-18，第 0 轮权重 | 复制同一份 E1 `initial.pt` |
| 数据与增强 | 固定划分，随机裁剪和水平翻转 | 相同 |
| 训练 | 100 轮，batch=128，SGD momentum=0.9，weight decay=0.0005，AMP，种子 42 | 相同 |
| 损失与选模 | 普通交叉熵，每轮验证，按准确率优先保存最佳 | 相同 |

E6 配置中的 `scheduler` 为 `fixed`。`min_learning_rate` 是与既有配置共用的余弦下限字段，E6 的实际学习率由 `learning_rate` 决定。`history.csv` 的 `lr` 列记录当轮真正使用的学习率，E6 的每条记录应为 `0.1`。权重保存优化器状态与已跑轮次，续训会核对固定学习率。

**启动与续训**

```powershell
# 在项目根目录打开 PowerShell
.\.venv\Scripts\python.exe -u train.py --config configs/e6.json
```

正式输出位于 `runs/E6/seed42`。可加 `--smoke` 检查流程，结果另存到 `runs/E6/smoke_seed42`。完成至少一轮并保存 `last.pt` 后，使用相同配置续训。

```powershell
.\.venv\Scripts\python.exe -u train.py --config configs/e6.json --resume
```

首轮未保存就中断时，可用 `--run-name seed42_retry1` 另开运行。绘图及评估命令中的 E6 路径使用实际目录。

**完成后的验证与对照**

```powershell
.\.venv\Scripts\python.exe plot_history.py --run-dir runs/E6/seed42
.\.venv\Scripts\python.exe evaluate.py --checkpoint runs/E6/seed42/best.pt --split validation
.\.venv\Scripts\python.exe compare_runs.py --run-dirs runs/E1/seed42 runs/E6/seed42
```

对照结果位于 `results/E1_vs_E6`。工具核对每轮实际学习率、相同初始哈希和其他训练条件。结合对照图右下的学习率、右上的验证损失和中下的验证准确率，看两组的后期波动、最后 10 轮均值和最佳轮。首轮在相同学习率下开始，之后的差异反映这两种给定策略的效果。最终选模前继续使用验证集。
