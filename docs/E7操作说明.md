**E7 验证集早停与 E1 对照**

E7 使用 E1 的 CIFAR ResNet-18 第 0 轮权重、固定的 CIFAR-10 数据划分、基础增强、普通交叉熵和种子 42。两组均以 `0.1` 为初始学习率，按 100 轮余弦计划衰减，下限 `0.00001`。batch size 为 128，SGD momentum 为 `0.9`，weight decay 为 `0.0005`，Dropout 为 `0.3`，在 CUDA 下启用 AMP。

**早停规则**

- 前 60 轮照常训练，用这段时间的最高验证准确率建立监控基准。
- 从第 61 轮起，验证准确率提高超过 `0.001`（0.10 个百分点）时更新基准并清零等待计数。验证集有 5,000 张，至少要多判对 6 张。其余轮次将计数加一。
- 连续 15 轮未达到改善阈值时，保存该轮的 `last.pt` 和日志，随后停止。到第 100 轮仍未触发时按预算完成。
- `best.pt` 始终选验证准确率最高的轮次。准确率相同时选验证损失更低的，更早轮次在两个指标均相同时保留。

回放 E1 种子 42 的 100 轮日志时，最后一次达到阈值在第 93 轮，第 100 轮的等待计数为 7。该回放预计会跑满预算，正式 E7 的耗时和成绩以实际运行为准。

**启动与续训**

在实验三目录运行正式训练。

```powershell
.\.venv\Scripts\python.exe -u train.py --config configs/e7.json
```

默认输出为 `runs/E7/seed42`。可先用 `--smoke` 检查数据、CUDA 和输出，结果另存到 `runs/E7/smoke_seed42`。早停边界由合成测试覆盖。

保存过 `last.pt` 后，可以继续同一次训练。续训会复核并恢复监控基准、等待计数、优化器和余弦调度状态。

```powershell
.\.venv\Scripts\python.exe -u train.py --config configs/e7.json --resume
```

如果首轮未保存就中断，可以加 `--run-name seed42_retry1` 从第 1 轮另开运行。后续评估、对照和续训使用实际运行名。

**评估与对照**

```powershell
.\.venv\Scripts\python.exe evaluate.py --checkpoint runs/E7/seed42/best.pt --split validation
.\.venv\Scripts\python.exe compare_runs.py --run-dirs runs/E1/seed42 runs/E7/seed42
```

对照结果默认保存在 `results/E1_vs_E7`。结合实际轮数、停止原因、逐轮耗时合计、最佳验证准确率和损失，说明早停省下的训练量和精度差异。逐轮耗时合计采用两组相同的统计口径，排除权重写盘。`history.csv` 还记录每轮的监控基准和等待计数。官方测试集在方案冻结后统一评估。
