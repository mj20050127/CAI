**E5 操作说明：在 CIFAR ResNet-18 上加入 CBAM**

E5 与 E1 对照，衡量单独加入 CBAM 后验证表现和训练成本的变化。E5 已完成 100 轮，最佳权重来自第 97 轮，完整验证集准确率为 95.38%。启动与续训命令适用于复现。详细结果见 [E5 对照分析](../results/E1_vs_E5/analysis.md)。

| 设置 | E1 | E5 |
|---|---|---|
| 模型 | CIFAR ResNet-18 | CIFAR ResNet-18＋CBAM |
| 参数量 | 11,173,962 | 11,261,786（+87,824，约 +0.79%） |
| 数据增强 | 随机裁剪和水平翻转 | 随机裁剪和水平翻转 |
| MixUp / CutMix | 关闭 | 关闭 |
| 样本 | 45,000 训练 / 5,000 验证 / 5,000 训练监测 | 相同划分 |
| 训练 | 100 轮，batch=128，SGD、余弦学习率衰减、AMP、种子 42 | 相同设置 |
| 初始权重 | E1 第 0 轮 | 共有层逐张量复制 E1 第 0 轮，CBAM 新层单独初始化 |

CBAM 放在 8 个残差块的第二个 BatchNorm 后、与捷径相加前。它先对通道加权，再对空间位置加权。通道模块将全局平均和最大池化的特征分别送入同一套两层映射，压缩率为 16。空间模块将通道平均值和最大值拼接，再用 7×7 卷积生成权重。两种权重均由 Sigmoid 得到，并与对应特征逐点相乘。方法依据见 [CBAM 原论文](https://arxiv.org/abs/1807.06521)。

共有初始化包含原始卷积、BatchNorm 参数和缓冲区，以及分类头。训练入口检查来源轮次、数据清单、种子、张量名称和形状，并保留两份哈希。`initial_shared_state_sha256` 应与 E1 初始状态哈希一致，`initial_state_sha256` 则涵盖 E5 完整模型。注意力初始化使用单独的 CPU 随机状态上下文，保留 E1 模型构造后的主随机数位置。完成 E5 后可从 E5 自己的 `initial.pt` 追溯 CBAM 的初始化。

**启动正式训练**

```powershell
# 在项目根目录打开 PowerShell
.\.venv\Scripts\python.exe -u train.py --config configs/e5.json
```

输出位于 `runs/E5/seed42`，启动日志会打印 CBAM 设置与两份哈希。需要先检查小规模流程时，可加 `--smoke`，它会另存到 `runs/E5/smoke_seed42`。正式训练至少完整保存一轮后，可用以下命令从 `last.pt` 续训。

```powershell
.\.venv\Scripts\python.exe -u train.py --config configs/e5.json --resume
```

如果在第一轮保存前中断，可加 `--run-name seed42_retry1` 从同一起点重跑，再在后续命令里使用实际运行目录。

**完成之后查看结果**

```powershell
.\.venv\Scripts\python.exe plot_history.py --run-dir runs/E5/seed42
.\.venv\Scripts\python.exe evaluate.py --checkpoint runs/E5/seed42/best.pt --split validation
.\.venv\Scripts\python.exe compare_runs.py --run-dirs runs/E1/seed42 runs/E5/seed42
```

对照结果写到 `results/E1_vs_E5`，包含验证指标、每类对比、逐样本预测变化、参数增量和训练曲线。若需要同设备推理耗时，使用合成输入运行以下命令。

```powershell
.\.venv\Scripts\python.exe benchmark_models.py --checkpoints runs/E1/seed42/best.pt runs/E5/seed42/best.pt --output results/E1_vs_E5/inference_benchmark.json
```

比较以 E1 的 95.30% 验证准确率为基线，并结合 Macro-F1、验证损失和耗时解释结果。E4 的 CutMix 结果留作后续组合参照。实施时的单批 AMP 与梯度检查见 [GPU 检查记录](../results/implementation_checks/E5/gpu_check.json)。
